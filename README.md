# frog federation

Straight copy of https://sites.google.com/kprschools.ca/frog-federation/home
— same 11 pages, same slugs, same text, headings and order. Served via
GitHub Pages at https://jchuanico.github.io/frogfederation/.

    ./download_images.sh      # optional: saves the 6 images into assets/

Linked Google Docs, Forms, Slides and Drive files stay as links (same as on
the original site). Most need a KPR school login to open.
